Samen één kaart? Zo zet je Firebase aan (5 min, gratis):

  1. Ga naar console.firebase.google.com en maak een project.
  2. Klik op Web (</>) om een web-app toe te voegen. Kopieer het firebaseConfig object.
  3. Ga naar Build → Firestore Database → Create database (start in testmodus).
  4. Plak de config hierboven, kies dezelfde team-code als je vriend, en klik Opslaan.
  5. Je vriend doet precies hetzelfde met dezelfde config + team-code. Klaar — jullie zien nu dezelfde bankjes! 🎉

Zonder Firebase werkt de app ook, maar dan blijft alles alleen op jouw telefoon staan.
